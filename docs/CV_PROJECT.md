# CV-ready project description

## MEV Sentinel — Ethereum Mempool Intelligence Platform

Developed a real-time Ethereum mempool intelligence platform using React.js, Node.js, Express.js, MySQL, Socket.IO, Recharts, Ethereum JSON-RPC/WebSockets, and Docker. The platform monitors pending transactions, recognizes major DEX router activity, decodes supported Uniswap-style swap calls, analyzes gas and transaction value patterns, generates heuristic MEV-related alerts, tracks pending-to-included transaction lifecycle, persists telemetry, and streams live analytics to a responsive dashboard.

### Strong bullet points

- Built a WebSocket-driven Ethereum pending-transaction ingestion pipeline with real-time Socket.IO delivery to a React dashboard.
- Implemented DEX router recognition, common swap calldata decoding, gas intelligence, whale detection, and heuristic MEV signal classification.
- Added block monitoring and pending transaction lifecycle tracking, including included and dropped states.
- Designed MySQL persistence, REST search/filter APIs, live analytics, Docker-based deployment, demo mode, and automated backend tests.
